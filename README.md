# Clínica Basilico

Plataforma Inteligente de Recuperação de Orçamentos.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

Para o ambiente da clínica em `http://localhost:3002`, veja [PostgreSQL local](docs/LOCAL_DEVELOPMENT.md).

## Validação

```bash
npm run lint
npm run build
```
